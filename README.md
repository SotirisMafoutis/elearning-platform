# EduQuiz — Πλατφόρμα Ηλεκτρονικής Μάθησης με Κουίζ Αυτοαξιολόγησης

Πλήρης εφαρμογή full-stack (JavaScript + Node.js + SQLite) με τρεις ρόλους χρηστών —
**Εκπαιδευόμενος**, **Εκπαιδευτής**, **Διαχειριστής** — όπως περιγράφονται στον πίνακα
προδιαγραφών: εγγραφή & παρακολούθηση μαθημάτων, κουίζ αυτοαξιολόγησης με χρονόμετρο,
προσωπικός πίνακας προόδου και πιστοποιητικά, τράπεζα ερωτήσεων, ανάλυση επιδόσεων,
έγκριση εκπαιδευτών/μαθημάτων, κατηγορίες, πρότυπα πιστοποιητικών και στατιστικά πλατφόρμας.
Κάθε μάθημα διαθέτει επίσης κείμενο θεωρίας και συνημμένα αρχεία (PDF, Word, εικόνες κ.λπ.)
με ενσωματωμένη προβολή PDF/εικόνων μέσα στην πλατφόρμα.

## Τεχνολογίες

- **Backend:** Node.js + Express 5, REST API
- **Βάση Δεδομένων:** SQLite (μέσω `better-sqlite3`) — αρχείο βάσης σε `data/app.db`, δημιουργείται αυτόματα
- **Frontend:** Καθαρή JavaScript (χωρίς framework), single-page app με hash routing
- **Αυθεντικοποίηση:** JWT + bcrypt
- **PDF Πιστοποιητικών:** `pdfkit` με ενσωματωμένη γραμματοσειρά DejaVu Sans (υποστήριξη ελληνικών)

## Εγκατάσταση & Εκτέλεση

Απαιτείται **Node.js 18+**.

```bash
npm install
npm start
```

Η εφαρμογή θα είναι διαθέσιμη στο **http://localhost:3000**.

Στην πρώτη εκτέλεση δημιουργείται αυτόματα το αρχείο βάσης δεδομένων (`data/app.db`) με:
- έναν έτοιμο λογαριασμό διαχειριστή
- 4 προεπιλεγμένες θεματικές κατηγορίες
- ένα προεπιλεγμένο πρότυπο πιστοποιητικού

### Δοκιμαστικός Λογαριασμός Διαχειριστή
```
Email:   admin@elearning.gr
Κωδικός: Admin123!
```
Οι λογαριασμοί εκπαιδευτή δημιουργούνται μέσω της φόρμας εγγραφής και χρειάζονται
έγκριση από τον διαχειριστή (καρτέλα «Εκπαιδευτές») πριν μπορέσουν να δημοσιεύσουν μάθημα.

### Αυτόματος έλεγχος (προαιρετικό)
Με τον διακομιστή σε λειτουργία, σε άλλο τερματικό:
```bash
npm test
```
Εκτελεί ένα πλήρες σενάριο (εγγραφή, έγκριση, δημιουργία μαθήματος/ερωτήσεων/κουίζ,
εγγραφή εκπαιδευόμενου, ολοκλήρωση ενοτήτων, συμμετοχή σε κουίζ, έκδοση πιστοποιητικού)
και επαληθεύει ότι όλα λειτουργούν σωστά.

## Πώς αντιστοιχούν οι λειτουργίες στον πίνακα προδιαγραφών

| Ρόλος | Λειτουργία | Πού υλοποιείται |
|---|---|---|
| Εκπαιδευόμενος | Εγγραφή & σειριακή παρακολούθηση με πρόοδο | `courses.js` (`/enroll`, `/modules/:id/complete` — κλειδώνει την επόμενη ενότητα μέχρι να ολοκληρωθεί η προηγούμενη) |
| Εκπαιδευόμενος | Κουίζ με χρονικό όριο, σκορ, σωστές απαντήσεις, επεξήγηση | `quizzes.js` (`/take`, `/submit`) + χρονόμετρο στο `views-learner.js` |
| Εκπαιδευόμενος | Προσωπικός πίνακας προόδου & πιστοποιητικό | `courses.js` (`/me/dashboard`) + `certificates.js` (λήψη PDF) |
| Εκπαιδευτής | Δόμηση μαθήματος σε ενότητες, βίντεο, σημειώσεις, προαπαιτούμενα | `courses.js` (`/courses`, `/courses/:id/modules`) |
| Εκπαιδευτής | Κείμενο θεωρίας & συνημμένα αρχεία (PDF/Word/εικόνες κ.λπ.), με προβολή PDF/εικόνων μέσα στην πλατφόρμα | `courses.js` (`/courses/:id/content`), `attachments.js` |
| Εκπαιδευτής | Τράπεζα ερωτήσεων (πολλαπλής επιλογής/Σ-Λ/αντιστοίχιση) με βαρύτητα & επεξήγηση | `quizzes.js` (`/courses/:id/questions`) |
| Εκπαιδευτής | Ανάλυση επιδόσεων ανά ερώτηση (ποσοστό επιτυχίας, δείκτης δυσκολίας) & ανά εκπαιδευόμενο | `analytics.js` |
| Διαχειριστής | Έγκριση εκπαιδευτών & δημοσίευσης μαθημάτων | `admin.js` (`/instructors/*`, `/courses/*`) |
| Διαχειριστής | Κατηγορίες & πρότυπα πιστοποιητικών | `admin.js` (`/categories`, `/certificate-templates`) |
| Διαχειριστής | Στατιστικά πλατφόρμας: εγγραφές, ποσοστά ολοκλήρωσης, σημεία εγκατάλειψης | `admin.js` (`/stats` — υπολογίζει το "funnel" ανά ενότητα και εντοπίζει πού αποχωρούν οι περισσότεροι εκπαιδευόμενοι) |

## Σημαντικές σχεδιαστικές αποφάσεις & απλοποιήσεις

- **Βίντεο ενοτήτων:** αποθηκεύεται ως URL (π.χ. σύνδεσμος YouTube που ενσωματώνεται αυτόματα)
  αντί για πραγματική αποθήκευση/μεταφόρτωση αρχείων βίντεο.
- **Ολοκλήρωση μαθήματος:** ένα μάθημα θεωρείται ολοκληρωμένο όταν ο εκπαιδευόμενος έχει
  ολοκληρώσει όλες τις ενότητες ΚΑΙ έχει πετύχει τη βάση επιτυχίας σε όλα τα κουίζ του
  μαθήματος· τότε εκδίδεται αυτόματα το πιστοποιητικό.
- **Επεξεργασία μαθήματος:** ο τίτλος, η περιγραφή, οι ενότητες και οι προαπαιτούμενες
  γνώσεις τροποποιούνται μόνο όσο το μάθημα είναι σε κατάσταση «πρόχειρο» ή «απορρίφθηκε» —
  ένα δημοσιευμένο μάθημα δεν αλλάζει δομικά εν κινήσει. Η **θεωρία/κείμενο μαθήματος** και
  τα **συνημμένα αρχεία** αποτελούν εξαίρεση σε αυτόν τον κανόνα και επεξεργάζονται από τον
  εκπαιδευτή ανά πάσα στιγμή, ακόμη και σε ήδη δημοσιευμένο μάθημα, αφού πρόκειται για
  συμπληρωματικό υλικό και όχι δομικό στοιχείο που επηρεάζει την έγκριση του μαθήματος.
- **Συνημμένα αρχεία:** επιτρέπονται τύποι PDF, Word, PowerPoint, Excel, εικόνες (PNG/JPG/GIF)
  και ZIP, με όριο 25MB ανά αρχείο· αποθηκεύονται στον δίσκο (`data/uploads/`) με τυχαία
  ονόματα αρχείων για αποφυγή συγκρούσεων, ενώ το αρχικό όνομα διατηρείται στη βάση για
  εμφάνιση. Μόνο εγγεγραμμένοι εκπαιδευόμενοι (ή ο ιδιοκτήτης-εκπαιδευτής/διαχειριστής)
  μπορούν να δουν ή να κατεβάσουν τα συνημμένα ενός μαθήματος.
- **Ασφάλεια σύνδεσης:** κωδικοί με bcrypt, JWT με μυστικό κλειδί που παράγεται αυτόματα
  και αποθηκεύεται σε `data/.jwt-secret` (ή ορίζεται μέσω μεταβλητής περιβάλλοντος
  `JWT_SECRET`). Ο έλεγχος έγκρισης εκπαιδευτή γίνεται πάντα φρέσκος από τη βάση δεδομένων
  σε κάθε αίτημα, ώστε μια έγκριση να ισχύει αμέσως.
- **Απεριόριστες προσπάθειες κουίζ:** εύλογο για πλατφόρμα αυτοαξιολόγησης — μετράει η
  καλύτερη προσπάθεια για την ολοκλήρωση του μαθήματος.

## Παραγωγική χρήση (production)

Για πραγματική ανάρτηση, ορίστε ένα δικό σας `JWT_SECRET` ως μεταβλητή περιβάλλοντος και
αλλάξτε τον κωδικό του δοκιμαστικού λογαριασμού διαχειριστή:
```bash
JWT_SECRET="το-δικό-σας-μυστικό-κλειδί" PORT=3000 npm start
```
